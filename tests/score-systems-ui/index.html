Test case UI — 3 hệ thống điểm

Checklist thủ công cho web (pet-health-web). Tick Pass khi case đạt — trạng thái lưu trong trình duyệt (localStorage).

Mở bằng trình duyệt: double-click file này hoặc Live Server.
Đã chốt: bỏ hai bậc danh hiệu dưới 30 điểm. Hồ sơ được duyệt luôn có tối thiểu 30 điểm nền → danh hiệu thấp nhất là “Trại mới”. Hồ sơ chưa duyệt cũng hiện “Trại mới”, không còn nhãn đỏ “Sắp bị khóa”.

Cách dựng dữ liệu để chạy

Điểm minh bạch đọc từ metadata.trust_score — seed thẳng biên 39/40/79/80 để kiểm màu nhanh. Điểm tuân thủ nằm ở metadata.compliance.score và nên thay qua luồng Admin xác nhận báo cáo để test luôn chế tài. Hai trang chi tiết (/trust, /compliance) chỉ mở được bằng tài khoản chủ trại.
