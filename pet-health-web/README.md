# Pet Marketplace Web

Next.js marketplace app for **https://pet-marketplace.org**.

## Deploy (pet-marketplace.org)

See **[DEPLOY.md](./DEPLOY.md)** for Vercel + DNS cutover from GitHub Pages, env vars, CORS, and smoke tests.

```bash
yarn build
yarn start   # local prod smoke on :3001
```

## Getting Started

```bash
yarn dev
```

Open [http://localhost:3001](http://localhost:3001).
